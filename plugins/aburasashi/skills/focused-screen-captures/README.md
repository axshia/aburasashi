# Focused Screen Captures

[Skill catalog](../README.md)

ドキュメント、チケット、PR 本文、レビューコメントで画面の特定の箇所を指すときに、実際の画面のキャプチャを撮り、対象以外を暗くして（バックドロップ）、対象を赤枠で囲んで（フォーカス）載せるスキルです。
viewport を固定して撮り、開発用のオーバーレイを隠し、[`scripts/focus-overlay.js`](scripts/focus-overlay.js) で枠を重ねます。
画像の直前には何を示すかの 1 文を置き、画像で分かることを文で繰り返さないようにします。

## 使い方

```text
$focused-screen-captures で、このチケットの「上部の帯に審査状況を表示します」の前に、帯の箇所が分かるキャプチャを入れてください。
```

```text
$focused-screen-captures で、検索フォームの「作成日時」と一覧の「作成日時」の列を 1 枚で囲んだキャプチャを撮ってください。
```

Claude Code では、プラグイン名を含むスラッシュコマンドでも呼び出せます。

```text
/aburasashi:focused-screen-captures サイドパネルの投稿者の欄を囲んだキャプチャを撮ってください。
```

## 適用範囲

- 対象：画面の箇所を指す文がある、ドキュメント、チケット、PR 本文、レビューコメント。
- 対象外：流れや構造の図（`excalidraw-diagrams`）、デザインとの照合（`figma-web-parity`）、OpenAPI のドキュメントのキャプチャ（`openapi-redoc-pr-screenshots`）、ターミナルへの返答。
- 必要なもの：撮る画面を開けるブラウザの自動操作のツール（Playwright、Chrome DevTools Protocol など）と、ダミーのデータ。
- 外部への書き込み：共有されているドキュメントに載せる前に、画像と差し込む位置を示して確認をもらいます。
