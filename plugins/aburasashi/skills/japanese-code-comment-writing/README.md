# Japanese Code Comment Writing

[Skill catalog](../README.md)

日本語のコードコメントと、テスト（spec）の説明文を、書いたときの文脈を知らないエンジニアに伝わる形で書くスキルです。
コードの言い換えではなく背景から書き、識別子と専門用語をそのまま使い、処理の動作は技術用語の動詞で書きます。

## 使い方

```text
$japanese-code-comment-writing で、この差分のコメントと spec の説明文を見直してください。
実装は変更しないでください。
```

Claude Code では、プラグイン名を含むスラッシュコマンドでも呼び出せます。

```text
/aburasashi:japanese-code-comment-writing このメソッドに、なぜこの検証が要るのかのコメントを書いてください。
```

コメントやテストの説明文が日本語のリポジトリで実装するときにも読み込みます。

## 書き換えの例

変更前：

```ruby
# 回答の値の形が正しいかどうかを返す。必須かどうかは見ず、空の値は正しいとみなします。
```

変更後：

```ruby
# 回答の型が正しいかどうかを判定する。必須要素に関しては、completed_for? で確認するため、blank 値は正常値とみなします。
```

「見る」を、処理を特定できる動詞に直し、空の扱いを `blank` で書いています。

## 適用範囲

- 対象：日本語のコードコメント、ドキュメントコメント（YARD、JSDoc、docstring など）、NOTE・TODO、テストの説明文の執筆、推敲、レビュー。
- 対象外：PR のインラインコメントとレビュー返信（`japanese-pr-writing`）、セッション中の返答（`japanese-native-writing`）、ドキュメント（`japanese-doc-writing`）、コミットメッセージ。
- 維持するもの：コードの動作。コメントと説明文だけを直す依頼で、実装は変更しません。
- リポジトリにコメントの言語や書式の規約があれば、それを優先します。
