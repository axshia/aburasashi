# Japanese Doc Review

[Skill catalog](../README.md)

書き上げた日本語のドキュメントを、初めて読む人の目で客観的にレビューするスキルです。
このセッションの文脈を持たない読み手に、本文と画像だけを渡し、画像が単独で何を示すか、ページの目的が冒頭で分かるか、どの言葉や参照でつまずいたかを答えてもらいます。
その答えと、見出し・言葉・文のつながり・画像の置き方・参照の観点を合わせて、場所・起きること・直し方の案の表で指摘を返します。

## 使い方

```text
$japanese-doc-review で、このチケットを共有する前に、初見の担当者が迷わず作業を始められるかレビューしてください。まだ書き換えないでください。
```

```text
$japanese-doc-review で、この設計メモの画像が、画像だけで何を示しているか分かるかを確かめてください。
```

Claude Code では、プラグイン名を含むスラッシュコマンドでも呼び出せます。

```text
/aburasashi:japanese-doc-review この調査結果のページをレビューしてください。
```

## 指摘の例

| 場所 | 起きること | 直し方の案 |
| --- | --- | --- |
| 見出し「表示する提出」 | 提出が複数あることを知らない読み手には、何の節か分からない | 「画面に表示する提出データについて」に変え、冒頭に「1 つの投稿に提出が複数作られます」の 1 文を足す |
| 「審査状況の表示について」の 1 文目 | 「上部の帯」がどこか分からない | 文の前に、帯を赤枠で囲んだキャプチャと「現在、審査状況は次の画像の赤枠の箇所に表示されています。」を置く |

## 適用範囲

- 対象：チケット、設計メモ、調査結果、手順書、wiki や Notion のページ、Markdown ファイルのレビュー。
- 対象外：PR の文面（`japanese-pr-writing`）、セッション中の返答（`japanese-native-writing`）、コードコメント（`japanese-code-comment-writing`）、社外に公開する記事（`japanese-article-writing`）。
- 書き換え：レビューだけを依頼した場合、ドキュメントは書き換えません。直す作業は `japanese-doc-writing` の基準で行います。
