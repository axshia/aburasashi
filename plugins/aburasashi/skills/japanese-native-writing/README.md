# Japanese Native Writing

[Skill catalog](../README.md)

セッション中にユーザーへ返す日本語を、何が分かったか・何をしたか・何を決めればよいかが 10 秒で分かる文章にするスキルです。
1 文目に結論を置き、要点を 2〜3 個に絞り、確かめていないことを結論と同じ重さで書きます。
読み手は現役のエンジニアとし、専門用語と識別子は言い換えずに使います。

## 使い方

```text
$japanese-native-writing で、次の作業状況をユーザー向けの報告にしてください。
確かめていないことと、決めてほしいことを分けてください。

ここに作業メモを貼り付けます。
```

Claude Code では、プラグイン名を含むスラッシュコマンドでも呼び出せます。

```text
/aburasashi:japanese-native-writing この調査結果を、結論から先にまとめてください。
```

日本語で返答する最初の機会と、コンテキスト圧縮のあとに読み込みます。

## 書き換えの例

変更前：

> 調査しました。原因: バリデーションが未選択時も走る → `errors` 二重追加。案 A で対応済み。

変更後：

> 予約フォームの設問「オプション」が未選択のとき、`errors` にエラーが 2 件追加される不具合を修正しました。
> テストはまだ実行していません。

対象の名前、起きること、確かめていないことを、述語まで書いた文にしています。

## 適用範囲

- 対象：ユーザーへの日本語の返答（説明、進捗報告、調査結果、選択肢の提示、質問）。
- 対象外：日本語ドキュメント（`japanese-doc-writing`）、PR の文面（`japanese-pr-writing`）、コードコメントと spec の説明文（`japanese-code-comment-writing`）、社外に公開する記事の本文（`japanese-article-writing`）、日本語以外の文章。
- 通常の入力：報告したい事実。ネットワークアクセスは不要です。
- 維持する情報：コード、コマンド、パス、識別子、エラー文、URL。
- 補わない情報：情報源にない手順、値、設定、エラー文。

返答を「です・ます」にすることは、ユーザーやリポジトリの指定がない場合の既定値です。
ユーザーが常体で書いていれば、返答も常体に合わせます。
