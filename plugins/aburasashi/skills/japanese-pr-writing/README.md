# Japanese PR Writing

[Skill catalog](../README.md)

PR のタイトル・本文・レビュー返信・検証報告を、自然でわかりやすい日本語に整えるスキルです。
新規の執筆にも、既存文書の推敲や文章レビューにも使えます。
文法と説明の順序を見直し、条件、技術用語、検証結果、Markdown の構造を保ちます。

## 使い方

```text
$japanese-pr-writing で、次の PR 本文を自然でわかりやすい日本語に整えてください。
技術的な意味、検証結果、既存の見出しを維持してください。

ここに PR 本文を貼り付けます。
```

```text
$japanese-pr-writing で、指定した差分と変更メモから日本語の PR 本文を作成してください。
リポジトリの PR テンプレートに従ってください。
検証結果は添付の実行ログを根拠にしてください。
```

「文法だけ」「タイトルだけ」「本文のみ」「修正理由も説明」などの指定もできます。
文面の作成だけを依頼した場合、GitHub への投稿は行いません。

Claude Code では、プラグイン名を含むスラッシュコマンドでも呼び出せます。

```text
/aburasashi:japanese-pr-writing この PR 本文を自然な日本語に整えてください。
```

## 書き換えの例

変更前：

> この変更の目的は、保存処理の見直しを行いました。

変更後：

> この変更では、保存処理を見直しました。

主語と述語を対応させ、原文にない変更理由は補っていません。
具体的な動作を説明する必要がある場合は、変更メモや差分で確認します。

## 適用範囲

- 対象：日本語の PR 文書の執筆、推敲、文章レビュー。
- 対象外：一般的な日本語の校正、コードレビューだけの依頼、投稿操作だけの依頼。
- 通常の入力：草稿、または対象の差分と変更メモ。推敲だけならネットワークアクセスは不要です。
- 維持する情報：条件と例外、数値、コマンド、識別子、リンク、検証状態、既存のテンプレート構造。
- 判断できない情報：複数の意味に取れる条件や矛盾は、推測で確定せず確認点として示します。

本文を「です・ます」にすることは、新規文書で指定がない場合の既定値です。
既存の自然な常体やプロジェクトの表記を、文法の誤りとして扱うことはありません。
