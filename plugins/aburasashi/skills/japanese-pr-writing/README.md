# Japanese PR Writing

[Skill catalog](../README.md)

PR のタイトル・本文・インラインコメント・レビュー返信・検証報告を、読み手のエンジニアが何をしたかを 10 秒で分かる日本語にするスキルです。
新規の執筆にも、既存文書の推敲や文章レビューにも使えます。
載せる情報を絞り、対象の名前と起きることを具体的な言葉で書き、条件、技術用語、検証結果、Markdown の構造を保ちます。

## 使い方

```text
$japanese-pr-writing で、指定した差分と変更メモから日本語の PR のタイトルと本文を作成してください。
検証結果は添付の実行ログを根拠にしてください。
```

```text
$japanese-pr-writing で、次の PR 本文を自然でわかりやすい日本語に整えてください。
技術的な意味、検証結果、既存の見出しを維持してください。

ここに PR 本文を貼り付けます。
```

「文法だけ」「タイトルだけ」「本文のみ」「修正理由も説明」などの指定もできます。
PR を作成・更新する前に、掲載するタイトルと本文の全文を提示して、確認を求めます。
文面の作成だけを依頼した場合、GitHub への投稿は行いません。
本文に詰め込むと長くなる補足は、差分に付けるインラインコメントの案として出します。

Claude Code では、プラグイン名を含むスラッシュコマンドでも呼び出せます。

```text
/aburasashi:japanese-pr-writing この PR 本文を見直してください。
```

## 書き換えの例

変更前：

> fix: 予約フォームのオプションが未選択のときにエラーが 2 つ付く不具合を修正する

変更後：

> fix: 予約フォームの設問「オプション」が未選択のとき、errors にエラーが過剰に追加される不具合を修正する

対象を「何の、何という名前のものか」で書き、起きることを、どこに何が起きるかを特定できる言葉に直しています。
具体的な動作は、変更メモや差分で確認します。

## 適用範囲

- 対象：日本語の PR 文書の執筆、推敲、文章レビュー。インラインコメントとレビュー返信を含みます。
- 対象外：セッション中の返答（`japanese-native-writing`）、ドキュメント（`japanese-doc-writing`）、コードコメント（`japanese-code-comment-writing`）、コードレビューだけの依頼、投稿操作だけの依頼。
- 通常の入力：草稿、または対象の差分と変更メモ。推敲だけならネットワークアクセスは不要です。
- 維持する情報：条件と例外、数値、コマンド、識別子、リンク、検証状態、既存のテンプレート構造。
- 判断できない情報：複数の意味に取れる条件や矛盾は、推測で確定せず確認点として示します。

節立ては、著者の直近の PR、リポジトリの PR テンプレートの順に合わせます。
本文を「です・ます」にすることは、新規文書で指定がない場合の既定値です。
